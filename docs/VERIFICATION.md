## Limits of this verification

- Screenshots were generated by Flutter's test renderer. A browser automation policy prevented interactive browser inspection; the web build is verified, but browser interaction was not independently exercised.
- The APK uses development signing for review. Installation and behaviour on a physical Android device have not been checked.
- iOS source is included; an iOS build and Apple signing have not been verified.
- No live Supabase project or Firebase credentials were supplied. Production authentication, notification delivery, storage configuration, and deployed database policies require the setup and checks in `LIVE_SETUP.md`.
- PGlite checks use a real PostgreSQL engine, but its compatibility shims do not replace verification on a deployed Supabase project.
- Screenshots use fictional school data and a fixed demonstration date. This project is a portfolio demonstration, not a completed production rollout.
